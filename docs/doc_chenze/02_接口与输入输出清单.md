# SAM3 接口与输入输出清单

基线：`main@6dab22eb529aa39c8e93c3451d2b289faf546fd4`，2026-11-09。所有条目均为源码/示例静态确认，未进行推理测试；代码块是供后续配环境时参考的调用示意，本轮未执行。

## 1. 面向业务的能力矩阵

| 编号 | 输入 | 用户操作/目的 | 已有接口 | 关键区别 |
|---|---|---|---|---|
| I01 | 图片 + 文本 | 找符合文字的对象，例如所有人 | `Sam3Processor.set_text_prompt` | 开放词汇概念分割，可能返回多个实例 |
| I02 | 图片 + 正示例框 | 框一个示例，找匹配对象 | `Sam3Processor.add_geometric_prompt(label=True)` | 概念提示，不保证只返回框内一个对象 |
| I03 | 图片 + 正/负框 | 用正例、反例区分目标 | 多次 `add_geometric_prompt`；可与文字组合 | `label=False` 为负示例；框提示在 state 中累积 |
| I04 | 图片 + 一个/多个正点 | 点击选中具体实例 | `model.predict_inst(point_coords=..., point_labels=...)` | 构建时必须 `enable_inst_interactivity=True`；可输出多个候选 |
| I05 | 图片 + 正负点 | 添加前景/背景点击修正掩膜 | 同上，标签 `1/0` | 多个点可用于同一个对象；不要误当多个对象 |
| I06 | 图片 + 实例框 | 拖框指定一个实例 | `model.predict_inst(box=...)` | 框是原图像素 XYXY，与 I02 坐标和语义均不同 |
| I07 | 图片 + 框 + 点 | 先框选再修正 | `predict_inst(box=..., point_coords=..., point_labels=...)` | 图片实例入口允许框和点组合 |
| I08 | 图片 + 上轮 mask logits | 结合新点击迭代修正 | `predict_inst(mask_input=...)` | 输入为上轮低分辨率 logits，不能直接把任意二值 PNG 当成该参数 |
| I09 | 多图/多查询 | 批量图片推理 | 实例：`set_image_batch` + `predict_inst_batch`；概念：`model(batch)` + `PostProcessImage` | 两条不同流程；概念批处理参考专门 notebook |
| V01 | 视频 + 文本 | 检测并跟踪符合概念的对象 | 会话 `add_prompt(text=...)` + `propagate_in_video` | 提示帧返回一帧；整段视频结果需要传播 |
| V02 | 视频 + 正/负示例框，可带文字 | 以某帧示例引导概念检测、跟踪 | 会话 `add_prompt(bounding_boxes=..., bounding_box_labels=...)` | 高层框提示走 detector；不会因传入 `obj_id` 就变成指定实例的框初始化 |
| V03 | 视频 + 正负点 | 新建具体对象，或修正已有对象 | 会话 `add_prompt(points=..., point_labels=..., obj_id=...)` | 新 ID 创建对象，已有 ID 修正对象；本分支不能同时提交 text/boxes |
| V04 | 视频 + 二值掩膜 | 从其他模块输出的 mask 初始化/修正对象 | **SAM 3** 会话 `add_mask` | SAM 3.1 高层入口没有对应底层方法，会抛 `NotImplementedError` |
| V05 | 视频 + 实例框/框和点 | 绕过概念检测，指定 ID 跟踪 | 底层 tracker 的 `add_new_points_or_box` | 属于 SAM 2 风格入口，不是高层 `bounding_boxes` 的同义操作 |
| V06 | 视频编辑过程 | 删除对象、重置、关闭、传播方向控制 | `remove_object` / `reset_session` / `close_session` / 流请求 | ID、会话、帧号需要由接入层维护 |
| A01 | 图片 + 复杂指令 | 需要多模态推理的对象选择 | Agent `run_single_image_inference` | 需额外 LLM 配置和回调，不能把复杂指令能力等同于基础文本编码器 |

笔刷、套索、多边形属于待确定的前端操作。当前没有独立同名高层请求；可按业务需要转成点击或掩膜再对接已有入口，转换规则需要新增封装。

## 2. 最容易接错的坐标约定

均以图片/原始视频帧左上角为原点，`x` 向右、`y` 向下。设原图宽高为 `W,H`。

| 入口 | 字段 | 格式 | 尺度 |
|---|---|---|---|
| 图片概念框 | `add_geometric_prompt(box=...)` | **CXCYWH**：中心 x、中心 y、宽、高 | `[0,1]`，分别除以 `W,H,W,H` |
| 图片实例点击 | `predict_inst(point_coords=...)` | `N×2`，`(x,y)` | 默认传原图像素；默认 `normalize_coords=True` 会在内部归一化 |
| 图片实例框 | `predict_inst(box=...)` | **XYXY**：左上 x/y、右下 x/y | 原图像素 |
| 视频高层点击 | `add_prompt(points=...)` | `N×2`，`(x/W,y/H)` | 默认 `rel_coordinates=True`，建议保持归一化输入 |
| 视频高层示例框 | `add_prompt(bounding_boxes=...)` | **XYWH**：左上 x、左上 y、宽、高 | `[0,1]`，每个框四个值分别归一化 |
| 视频底层实例框 | `tracker.add_new_points_or_box(box=...)` | **XYXY** | 默认相对坐标：`[x0/W,y0/H,x1/W,y1/H]` |

例：`W=1000,H=500`，拖框像素坐标 `[100,50,300,250]`：

- 图片实例框：`[100,50,300,250]`。
- 图片概念框：`[0.2,0.3,0.2,0.4]`。
- 视频高层示例框：`[0.1,0.1,0.2,0.4]`。
- 视频底层实例框：`[0.1,0.1,0.3,0.5]`。

视频的 `rel_coordinates=False` 不能直接按图片接口理解为“接受原图像素并自动换算”；当前底层代码只在 True 时乘模型输入尺寸。接入时统一使用默认相对坐标更清楚。[底层处理](https://github.com/Alwaysssssss/sam3/blob/6dab22eb529aa39c8e93c3451d2b289faf546fd4/sam3/model/sam3_tracking_predictor.py#L180)

前端如果显示的是缩放/裁剪/留黑后的画布，先把鼠标坐标映射回原始图像有效区域，再按目标接口转换；返回 mask 也需要进行反向显示映射。

## 3. 图片接口

### 3.1 构建与缓存图片

```python
from PIL import Image
from sam3.model_builder import build_sam3_image_model
from sam3.model.sam3_image_processor import Sam3Processor

model = build_sam3_image_model(
    checkpoint_path="/path/to/sam3.pt",  # 后续准备权重时再替换
    enable_inst_interactivity=True,     # 图片点击/实例框需要
    compile=False,
)
processor = Sam3Processor(model)
state = processor.set_image(Image.open("/path/to/image.jpg").convert("RGB"))
```

模型实例可复用；`state` 对应这张图片的特征和提示。图片输入优先使用 PIL RGB。`set_image_batch` 虽然类型标注写了其他类型，当前实现实际断言列表首项是 PIL 图片。

### 3.2 文本与示例框

```python
out = processor.set_text_prompt(prompt="person", state=state)

# 改做纯示例框任务：清理文字及先前提示，但保留图片特征
processor.reset_all_prompts(state)
out = processor.add_geometric_prompt(
    box=[0.2, 0.3, 0.2, 0.4], label=True, state=state
)
# 再加一个负例框，排除不希望选择的类型
out = processor.add_geometric_prompt(
    box=[0.7, 0.3, 0.1, 0.2], label=False, state=state
)
```

`set_text_prompt` 会替换文字，但不会自动删除已有几何提示；`add_geometric_prompt` 会追加框。跨不同任务时使用 `reset_all_prompts`；文字+框联合提示时保留两者。`set_confidence_threshold(threshold, state)` 调整实例置信度过滤阈值，并可能重跑 grounding。[图片处理器](https://github.com/Alwaysssssss/sam3/blob/6dab22eb529aa39c8e93c3451d2b289faf546fd4/sam3/model/sam3_image_processor.py#L114)

概念分割输出保存在同一个 state 中：

| 字段 | 形状/类型 | 语义 |
|---|---|---|
| `masks` | Torch bool，`N×1×H×W` | 原图分辨率二值掩膜 |
| `boxes` | Torch float，`N×4` | 原图像素 XYXY |
| `scores` | Torch float，`N` | 过滤后的实例置信度，不是百分比准确率 |
| `masks_logits` | Torch float，`N×1×H×W` | 虽然名称含 logits，当前实现已做 sigmoid，是概率图；不要与实例接口返回的低分辨率原始 logits 混用 |

### 3.3 点击、实例框和迭代修正

```python
import numpy as np

masks, scores, low_res_logits = model.predict_inst(
    state,
    point_coords=np.array([[200, 150]], dtype=np.float32),
    point_labels=np.array([1], dtype=np.int32),
    multimask_output=True,
)
best = int(np.argmax(scores))

# 下一轮提交该对象的全部点击：一个正点、一个负点
masks, scores, low_res_logits = model.predict_inst(
    state,
    point_coords=np.array([[200, 150], [280, 170]], dtype=np.float32),
    point_labels=np.array([1, 0], dtype=np.int32),
    mask_input=low_res_logits[best:best + 1],
    multimask_output=False,
)

# 实例框也可以与同一对象的正负点击组合
masks, scores, low_res_logits = model.predict_inst(
    state, box=np.array([100, 50, 300, 250], dtype=np.float32),
    multimask_output=False,
)
```

单对象情况下，输出为 NumPy：`masks` 是 `C×H×W`，`scores` 为 `C`，`low_res_logits` 是 `C×h×w`。`multimask_output=True` 通常返回 3 个候选，用分数选候选；False 返回单个。多框输入会增加相应批维度，不能把候选维度误认为对象 ID。`return_logits=True` 会改变高分辨率 masks 的语义。[参数与输出定义](https://github.com/Alwaysssssss/sam3/blob/6dab22eb529aa39c8e93c3451d2b289faf546fd4/sam3/model/sam1_task_predictor.py#L234)

图片 API 不自动维护每个对象的跨轮交互历史；接入层需要保存点击、候选选择及相应 logits。实例批处理使用 `processor.set_image_batch([...])` 和 `model.predict_inst_batch(...)`；概念批处理参考 [批推理 notebook](https://github.com/Alwaysssssss/sam3/blob/6dab22eb529aa39c8e93c3451d2b289faf546fd4/examples/sam3_image_batched_inference.ipynb)，通过数据点构建、`collate`、`model(batch)`、`PostProcessImage.process_results` 完成。单图 `set_text_prompt` 的后处理依赖 `original_height/original_width`，不能直接接在 `set_image_batch` 后当完整批处理接口。

## 4. 视频高层会话接口

### 4.1 构建与资源

```python
from sam3.model_builder import build_sam3_predictor

predictor = build_sam3_predictor(
    version="sam3", checkpoint_path="/path/to/sam3.pt", compile=False
)
```

SAM 3.1 使用 `version="sam3.1"` 和相应权重，另有 `max_num_objects`、`multiplex_count`、`use_fa3`、`warm_up` 等参数。当前部署未核验依赖和硬件兼容性。

资源加载器静态支持单张图片、图片目录、视频文件和 PIL 图片列表。常规接入建议先统一为服务器本地文件/目录：图片扩展名包括 jpg/jpeg/png/bmp/tiff/webp；视频包括 mp4/mov/avi/mkv/webm。扩展名被识别不等于解码一定成功，仍依赖后续环境和编码格式。图片目录优先按数字文件名排序，无法解析数字时按字典序；请明确顺序和帧率。[资源加载源码](https://github.com/Alwaysssssss/sam3/blob/6dab22eb529aa39c8e93c3451d2b289faf546fd4/sam3/model/io_utils.py#L31)

### 4.2 请求目录

以下是 Python 字典中的 `type` 值，**不是 URL**。除传播外均调用 `predictor.handle_request(request)`。

| type | 必填字段 | 可选字段/默认 | 返回与限制 |
|---|---|---|---|
| `start_session` | `resource_path` | `session_id=None`；`offload_video_to_cpu=False`；`offload_state_to_cpu=False` | `{"session_id": ...}` |
| `add_prompt` | `session_id`, `frame_index`，以及有效提示 | text/points/boxes 与标签、obj_id、清理标志等，见下表 | `{"frame_index": i, "outputs": {...}}`；只返回当前提示帧 |
| `add_mask` | `session_id`, `frame_index`, `obj_id`, `mask` | 无 | 同上；SAM 3 支持，SAM 3.1 不支持 |
| `remove_object` | `session_id`, `obj_id` | `frame_index=0`, `is_user_action=True` | SAM 3 返回 `is_success`；SAM 3.1 公共基类可返回帧输出，不宜假定两版完全一致 |
| `reset_session` | `session_id` | 无 | `{"is_success": True}`，清理提示/跟踪状态，保留会话资源 |
| `cancel_propagation` | `session_id` | 无 | `{"is_success": True}`；底层不支持时是 no-op；SAM 3.1 有相应方法，SAM 3 无该底层方法 |
| `close_session` | `session_id` | `run_gc_collect=True`, `clear_cache_threshold=80` | `is_success`；实际清理且启用 gc 时可附带 `gpu_mem`；重复关闭容忍 |
| `propagate_in_video` | `session_id` | 见传播参数表 | **使用 `handle_stream_request`**，逐帧 yield |

`shutdown()` 是直接方法，用于 predictor 生命周期结束时清理；不是一种 request type。请求分发的完整定义见 [公共基类](https://github.com/Alwaysssssss/sam3/blob/6dab22eb529aa39c8e93c3451d2b289faf546fd4/sam3/model/sam3_base_predictor.py#L55)。

### 4.3 add_prompt 字段

| 字段 | 类型/默认 | 用途与版本差异 |
|---|---|---|
| `frame_index` | int，0 起始 | 原始视频中的提示帧 |
| `text` | str / None | 文本概念；高层概念路径会重置跟踪状态，换查询时应显式 reset |
| `bounding_boxes` | `N×4` 列表/张量 / None | 相对 XYWH 的概念示例框 |
| `bounding_box_labels` | `N`，正/负 `1/0` | 与框一起提供 |
| `points` | `N×2` 列表/张量 / None | 相对坐标点击 |
| `point_labels` | `N`，前景/背景 `1/0` | 与点击一起提供 |
| `obj_id` | int / None | 点击分支必须给；新对象使用未占用 ID，修正对象使用返回的已有 ID |
| `rel_coordinates` | bool，True | 作用于点击；框概念路径仍要求归一化 XYWH |
| `clear_old_points` | bool，True | SAM 3.1 点分支可以控制累积；SAM 3 的实例方法签名不接收此字段，其内部点击调用固定清旧点，应每次发送该对象需要保留的全部点击 |
| `clear_old_boxes` | bool，True | SAM 3.1 概念分支当前断言必须为 True；SAM 3 不接收这一可调字段，不承诺 False 累积 |
| `output_prob_thresh` | float，默认 0.5 | 公共层有字段；SAM 3.1 底层接收，SAM 3 的高层 add_prompt 签名不接收，公共层会过滤掉 |

点击分支明确断言 `text is None` 且 `bounding_boxes is None`；图片实例接口允许框+点组合，不能据此推断视频高层也允许。[SAM 3 分支](https://github.com/Alwaysssssss/sam3/blob/6dab22eb529aa39c8e93c3451d2b289faf546fd4/sam3/model/sam3_video_inference.py#L1478)、[SAM 3.1 分支](https://github.com/Alwaysssssss/sam3/blob/6dab22eb529aa39c8e93c3451d2b289faf546fd4/sam3/model/sam3_multiplex_tracking.py#L2693)

### 4.4 传播参数

```python
request = {
    "type": "propagate_in_video",
    "session_id": session_id,
    "propagation_direction": "both",       # both / forward / backward
    "start_frame_index": 0,                 # 也可为其他提示帧或省略
    "max_frame_num_to_track": None,
    "output_prob_thresh": 0.5,
    "force_tracker_propagation": False,
    "evict_cached_frame_outputs": False,
}
```

公共层默认方向为 both，起始帧为 None（由模型选择），最长帧数为 None。`output_prob_thresh` 和 `force_tracker_propagation` 是否传到底层取决于方法签名；SAM 3 传播接收后者，不接收前者。`evict_cached_frame_outputs=True` 在公共层逐帧移除缓存，后续再交互/取缓存的需求要另外确认。

双向结果按两次传播依次产出，不保证按全局帧号升序，也不应假设每个帧号只出现一次；调用方按 `frame_index` 组织结果。[传播实现](https://github.com/Alwaysssssss/sam3/blob/6dab22eb529aa39c8e93c3451d2b289faf546fd4/sam3/model/sam3_base_predictor.py#L302)

### 4.5 一段完整调用流程

```python
session_id = predictor.handle_request({
    "type": "start_session", "resource_path": "/path/to/video.mp4"
})["session_id"]

try:
    # 三选一：文本概念 / 示例框概念 / 点击指定实例
    prompt = {"text": "person"}
    # prompt = {"bounding_boxes": [[0.1, 0.1, 0.2, 0.4]],
    #           "bounding_box_labels": [1]}
    # prompt = {"points": [[0.2, 0.3]], "point_labels": [1], "obj_id": 1001}
    first = predictor.handle_request({
        "type": "add_prompt", "session_id": session_id, "frame_index": 0,
        **prompt,
    })
    for item in predictor.handle_stream_request({
        "type": "propagate_in_video", "session_id": session_id,
        "propagation_direction": "forward", "start_frame_index": 0,
    }):
        frame_index = item["frame_index"]
        masks = item["outputs"]["out_binary_masks"]
        # 由接入层逐帧消费/编码/持久化，不必把全部全分辨率 mask 留在内存
finally:
    predictor.handle_request({"type": "close_session", "session_id": session_id})
    predictor.shutdown()  # 独立脚本结束；长驻进程应在服务退出时调用
```

SAM 3 从二值 mask 初始化可将提示步骤替换为：

```python
predictor.handle_request({
    "type": "add_mask", "session_id": session_id, "frame_index": 0,
    "obj_id": 1001, "mask": binary_mask,  # 建议与原始帧对齐的 H×W bool
})
```

这不是 SAM 3.1 可通用调用的操作。公共层把 mask 转成 bool，若输入的是概率图，需调用方先明确阈值；任何非零值直接转 bool 的语义与概率阈值不同。[mask 请求实现](https://github.com/Alwaysssssss/sam3/blob/6dab22eb529aa39c8e93c3451d2b289faf546fd4/sam3/model/sam3_base_predictor.py#L230)

### 4.6 高层视频输出

`add_prompt` 和每个流式结果的对象数据均位于 **`response["outputs"]`** 内：

| 字段 | NumPy 形状 | 语义 |
|---|---|---|
| `out_obj_ids` | `N` | 当前帧输出对象 ID；后续修正/删除使用此 ID |
| `out_probs` | `N` | 对象分数；不作为准确率，也不直接与图片实例候选分数横比 |
| `out_boxes_xywh` | `N×4` | 相对坐标、左上角 XYWH；与图片输出像素 XYXY 不同 |
| `out_binary_masks` | `N×H×W` bool | 对齐原始视频帧的二值掩膜 |
| `frame_stats` | 可选/可能为 None | 版本或路径相关统计信息，不宜作为强制业务字段 |

不同帧的 N 可以变化，也可能为 0。对象 ID 是会话内跟踪标识；是否要求遮挡恢复后 ID 一致，需要专门评估，不能从接口名称推断质量保证。没有生成“已画好框的成品视频”这一统一响应；画框、掩膜叠加、视频编码属于后续封装。[SAM 3 输出](https://github.com/Alwaysssssss/sam3/blob/6dab22eb529aa39c8e93c3451d2b289faf546fd4/sam3/model/sam3_video_inference.py#L432)

## 5. 视频底层 tracker：指定 ID 的实例框

如果业务需要“拖框锁定这一个对象，再沿视频跟踪”，现有官方示例有这条独立流程：

```python
from sam3.model_builder import build_sam3_video_model

sam3_model = build_sam3_video_model(checkpoint_path="/path/to/sam3.pt")
tracker = sam3_model.tracker
tracker.backbone = sam3_model.detector.backbone
tracking_state = tracker.init_state(video_path="/path/to/frames")

result = tracker.add_new_points_or_box(
    inference_state=tracking_state, frame_idx=0, obj_id=1001,
    box=np.array([[0.1, 0.1, 0.3, 0.5]], dtype=np.float32),
    rel_coordinates=True,
)
```

也可传 `points` + `labels`，或通过 `add_new_mask` 初始化。框和点组合时需要 `clear_old_points=True`，以便框先于点击进入提示。`add_new_points_or_box` 和 `add_new_mask` 均返回 `(frame_idx, obj_ids, low_res_masks, video_res_masks)`，其中当前实现的 `low_res_masks` 为 None。`video_res_masks` 是分数张量，示例通过 `> 0.0` 得到二值 mask，与高层已返回 bool 的结果不同。传播 `tracker.propagate_in_video(...)` 需要显式传起始帧、最长跟踪帧数、反向标志，逐帧返回五项 `(frame_idx, obj_ids, low_res_masks, video_res_masks, obj_scores)`。[tracker API](https://github.com/Alwaysssssss/sam3/blob/6dab22eb529aa39c8e93c3451d2b289faf546fd4/sam3/model/sam3_tracking_predictor.py#L180)

这是需要算法侧封装的底层能力，不能把高层会话 state 与这里的 tracking_state 混用。此处只标明入口；完整生命周期、内存预处理和传播步骤以 [官方 SAM 2 风格 notebook](https://github.com/Alwaysssssss/sam3/blob/6dab22eb529aa39c8e93c3451d2b289faf546fd4/examples/sam3_for_sam2_video_task_example.ipynb) 为参考，后续再运行核验。

## 6. 还不是现成对外协议的部分

- SDK 字典包含 Torch/NumPy 数据，不能直接视为 JSON；需约定 mask 的 PNG/RLE、dtype、维度、坐标和错误结构。
- 上传文件、远程 URL 拉取、鉴权、排队、会话归属、真正的网络流式推送尚需服务层封装。
- `handle_stream_request` 是 Python 生成器，不等于 WebSocket/SSE 接口。
- `session_expiration_sec` 在 SAM 3.1 中会记录过期元数据；当前公共层没有提供后台清理服务，不能只凭参数承诺会话自动超时回收。
- `cancel_propagation` 的返回成功不代表 CUDA 工作立即可中断；取消语义和同会话并发需要单独设计与验证。

这些是后续业务方向确定后再选择的工程范围，本轮未实现。
